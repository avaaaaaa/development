* When working with dates in the browser, it may be useful sometimes to use a library that makes that process easier. Traditionally, developers were using a very popular library called moment.js. However, this library is currently not maintained due to how old (and thus big in size) it is.

The new and recommended alternative is date-fns.
it is a collection of functions that make it easier to work with dates in js

installing date-fns
	npm install date-fns

importing from date-fns
	import {addYears} from "date-fns";


* addYears example
const rightNow = new Date();
console.log(rightNow);

const years = 5;
const yearsLater = addYears(rightNow, years);
console.log(yearsLater);


** dynamic import

import("date-fns").then(module => {
  console.log(module);
  const years = 10;
  const yearsLater = module.addYears(new Date(), years);
  console.log(yearsLater);
});

// or

const module = await import("date-fns");
console.log(module);
const years = 10;
const yearsLater = module.addYears(new Date(), years);
console.log(yearsLater);


// however, these two examples above loads entire "date-fns" library
// if we only need ".addYears()", we can do the following:

import("date-fns/addYears").then(module => {
  console.log(module);
  const years = 10;
  const yearsLater = module.default(new Date(), years);
  console.log(yearsLater);
});

// or

const module = await import("date-fns/addYears");
console.log(module);
const years = 10;
const yearsLater = module.addYears(new Date(), years);
console.log(yearsLater);

// check the console.log(module) for the second approach
// notice that we could use "module.default()" aswell
