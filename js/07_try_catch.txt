* when a function call might fail or cause errors,
it is recommened to wrap the function call with try-catch block
this will prevent errors breaking the code, so we can recover from them


*
console.log("Step 1");
try {
    nonExistentFunction();
} catch (error) {
    console.error(error); // Uncaught ReferenceError: nonExistentFunction is not defined
}
console.log("Step 2");


if the function above was called without try-catch,
	the program would be terminated with an uncaught error after logging "Step 1"
with try-catch, we can still keep code running and take necessary actions about possible errors
	so we will see "Step 1", some information about caught error and then "Step 2"
catch{...} block will be skipped if there are no errors encountered
	"Step 1", and then "Step 2"


* throwing exceptions

const isValidName = name => (name?.trim?.().length ?? 0) > 7;

const sayHello = name => {
    if(!isValidName(name)){
        throw new Error("name must be at least 8 characters without spaces at the beginning & end");
    }
    console.log(`Welcome ${name.trim()}`);
}

try{
    sayHello("   12  34567    ");
} catch(error){
    console.error(error.message);  // prints the error message if there is any error
    // console.error(error) gives more details
}
console.log("the program continues...");


* finally block
we can add "finally" block to the end of try-catch block
try{
	...
} catch(error){
	...
} finally{
	...
}

assuming there will be no error thrown within try block,
	first, try{} will be executed 
	second, finally{} will be executed
assuming there will be an error thrown within try block,
	first, try{} will be executed until the line where the error will be thrown
	second, catch{} will be executed
	third, finally{} will be executed


** example
try{
    console.log("try1");
    throw new Error("error");
    console.log("try2");
} catch(error){
    console.error("error1");
} finally{
    console.log("finally1");
}
console.log("program continues...");

output:

try1
error1
finally1
program continues...

if  throw new Error('error');  is deleted, the output would be:

try1
try2
finally1
program continues...

** example
function test(){
    try{
		console.log("try");
      	return 1;
      	throw "error";
    }catch(error){
        console.log("error");
        return 2;
    }finally{
        console.log("finally");
        return 3;
    }
}

const data = test();
console.log(data);

// try
// finally
// 3

// if "return 1" is commented out, the output:
// try
// error
// finally
// 3
