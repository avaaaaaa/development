* debugger statement
we can use "debugger" statement to pause the execution so that we can inspect the current situation

func1();
debugger;
func2();

// execution pauses after "debugger;" statement
// so we can inspect the changes after func1() call


* the more logs to the console, the harder to map the console output with the corresponding log
to make it easier, we can wrap the variable with {}, or we can add another log next to the variable

const sum = (a, b) => {
    console.log(a); // 1
    console.log(b); // 3
    let total = a + b;
    console.log(total); // 4
    return total;
}

// one way to make it more readable
const sum = (a, b) => {
    console.log({a}); // {a: 1}
    console.log({b}); // {b: 3}
    let total = a + b;
    console.log({total}); // {total: 4}
    return total;
}

// another way
const sum = (a, b) => {
    console.log(a, "a"); // 1 "a"
    console.log(b, "b"); // 3 "b"
    let total = a + b;
    console.log(total, "total"); // 4 "total"
    return total;
}


* wrapping the value with {} doesn't work on object properties though
but we can still use the second approach

const user = {
  name: "gg",
  age: 18,
}
console.log({user.age});  // SyntaxError
console.log("age", user.age);  // "age" 18
