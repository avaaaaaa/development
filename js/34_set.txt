* set is introduced in ES2015
it is a collection of unique values.
Maps store key-value pairs, whereas Sets store values only.
The values in a Set are unique and that makes it the best use case to use a Set.


const set = new Set();

set.add(10);
set.add(5);
set.add(10);
set.add(5);
set.add(7);
console.log(set.size); // 3
console.log(set); // Set(3) {10, 5, 7}
// it removes duplicate values automatically


similarly, you can create a set from an array to filter out the duplicate values
const numbers = [1, 2, 3, 1, 3, 4];
const set = new Set(numbers);
console.log(set); // Set(4) {1, 2, 3, 4}


** iteration
const tags = new Set();
tags.add("JavaScript");
tags.add("Tutorial");

tags.forEach(tag => {
    console.log(tag); // "JavaScript", then "Tutorial"
});


** iteration
for (const tag of tags) {
	console.log(tag); // "JavaScript", then "Tutorial"
}


*.has()
The .has(value) method, allows you to quickly check whether the set contains a certain value or not. This is generally quicker than arrays (but remember that you will probably not feel the difference unless you're storing millions of items).
