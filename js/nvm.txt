* nvm (node version manager) allows you to quickly install and use different versions of node via the command line.

source: https://github.com/nvm-sh/nvm

installing nvm
	/usr/bin/curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
		restart the terminal after running this command

# Download and install Node.js:
nvm install 24

# Verify the Node.js version:
node -v # Should print "v24.21.0".

# Verify npm version:
npm -v # Should print "11.19.0".


# Download & install a different version of Node.js
nvm install 22

# Use a differenct version of Node.js
nvm use 22
