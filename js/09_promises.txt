* promises provide clearer syntax than callback pattern
.then(callback) replaces the async success callback, will run after finishing the function
.catch(callback) replaces the async error callback, will run if there is an error during execution
we can call then(), and catch() on functions that return a new Promise


* example
const wait = milliseconds => {
    // this function returns a new promise
    return new Promise(resolve => {
        setTimeout(() => {
            resolve();
        }, milliseconds);
    });
}

wait(1_000).then(() => {
    console.log("waited 1 second");
});


* promises can have 3 states
pending, fulfilled, rejected
when a promise is created, it will start in the pending state
when it has been completed successfully, then it will become fullfilled
when an error has occured, it will become rejected


*
// wait() from the previous example
const result = wait(1_000);
console.log(result); // A
result.then(() => {
    console.log(result); // B
});
console.log(result); // C
// A: Promise {<pending>}
// C: Promise {<pending>}
// B: Promise {<fulfilled: undefined}
