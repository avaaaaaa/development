* <form> elements are used to group related inputs together
Forms are often combined with the fetch API
if there are multiple <form> elements
	when one of them gets submitted, only its inputs will be sent


* the submit event
these will trigger the submit event:
	clicking on the submit button
	pressing enter on the keyboard while the focus of the mouse cursor is on one of the form inputs

requirements for the submit event
	have a <form> element
	have at least <input> or <textarea> inside of <form>
	have a button with type "submit":
		<input type="submit" value="click to submit">
		<button type="submit">click to submit</button>

the submit event fires only on the <form>
	so we need to attach the submit event listener on the <form>, not on the <button> 


an example:
<form id="address-form">
    <input type="text" placeholder="Enter your address">
    <input type="submit" value="Save">
</form>

const form = document.querySelector("#address-form");
form.addEventListener("submit", event => {
    // event callback (when the form is submitted)
});


* event.preventDefault()
when a form is submitted, the browser will collect and send all the inputs to the backend of your website
	by default, the backend is the same URL as where the user submitted the form (the current webpage)
		and this will cause the current page to be reloaded
		you can override the default with "action" attribute of the <form>


for example:
If you have the index.html open and you fill in your email & password and click submit, the browser will send your email and password to the index.html page which will make the page refresh/reload.

This is the default behavior for forms. The reason behind it is rather historical. Before the fetch API (and its recent predecessor) made it to browsers, this was the only way of submitting data from the frontend to the backend.

However, nowadays we've got the fetch API, and thus we don't want to reload the page every time the user sends some information. and we can prevent this default behavior with event.preventDefault()

form.addEventListener("submit", event => {
    event.preventDefault();
    // the form will not reload anymore
});

but sometimes you want to rely on this behavior if you're not using fetch. That would be the case if your backend is written in Rails/Laravel/Symfony/etc. and you'd like to submit the data without using fetch.

* form.reset()
After a user submits, you often want to empty the form so they can start fresh or just so they get visual feedback that something happened. Instead of clearing each input manually with input.value = "", call .reset() on the form. This restores every field to its initial state: empty for text inputs, unchecked for checkboxes, and back to the default option for dropdowns.


const form = document.querySelector("form");

form.addEventListener("submit", event => {
    event.preventDefault();

    form.reset(); // clears all the inputs
});


* FormData class
when the <form> has a lot of input fields, it won't be convenient to get their values with document.querySelector(). this will lead to code repetition. instead, we can make use of FormData class
for such cases

FormData matches input values with "name" attribute of the <input>
so, if <input> does not have "name" attribute, it won't be registered in FormData
also, if <input> has "disabled" attribute, it won't be registered in FormData even it has "name"


<form id="signup-form">
    <input type="text" name="username" placeholder="Username">
    <input type="email" name="email" placeholder="Email">
    <input type="password" name="password" placeholder="Password">
    <input type="submit" value="Sign up">
</form>
<script>
    const form = document.querySelector("#signup-form");
    form.addEventListener("submit", event => {
        event.preventDefault();
        const data = new FormData(form);
        console.log(data);
    });
</script>

output:
FormData(3) { username → "test", email → "test@test.com", password → "test" }


** FormData.get(inputName)
returns the value of the <input> whose "name" attribute is "inputName"
	if there are multiple inputs that have the same "name", returns only the value of the first one 

// data from the previous example
data.get("username");
	returns "test"
data.get("email");
	returns "test@test.com"

<form id="register-form" novalidate>
    <label for="register-name">Name</label>
    <input id="register-name" name="name" type="text" placeholder="Enter your name">
    <label for="register-email">Email</label>
    <input id="register-email" name="email" type="email" placeholder="Enter your email">
    <label for="register-password">Password</label>
    <input id="register-password" name="password" type="password" placeholder="Enter your password">
    <input type="submit" value="Register" id="submit-button">
</form>

<script>
    const form = document.querySelector("#register-form");
    form.addEventListener("submit", event => {
        event.preventDefault();
        const data = new FormData(form);
        completeRegistration(
            data.get("name"),
            data.get("email"),
            data.get("password")
        );
    });

    function completeRegistration(name, email, password) {
        console.log({name, email, password});
    }
</script>


** FormData.getAll(inputName)
returns the array of the all <input>s that have the same value of "name" attribute as "inputName"


** getting all the ticked checkboxes
<form id="prefs-form">
    <label>
        <input type="checkbox" name="interests" value="music">
        Music
    </label>
    <label>
        <input type="checkbox" name="interests" value="sports">
        Sports
    </label>
    <label>
        <input type="checkbox" name="interests" value="movies">
        Movies
    </label>
    <input type="submit" value="Save">
</form>

<script>
    const form = document.querySelector("#prefs-form");
    form.addEventListener("submit", event => {
        event.preventDefault();
        const data = new FormData(form);
        console.log(data.getAll("interests"));
    });
</script>

// Music and Sports are selected then submitted
// the output: Array [ "music", "sports" ]
